# GAMEPLAY SPEC (구현 기준값)

튜닝값은 `Data/kart_stats.json`과 `Data/items.json`에 있습니다. 코드를 바꾸지 않고 재실행만 하면 반영됩니다.

| 항목 | 값 |
|---|---|
| 최고속 | 30 m/s (108 km/h). 부스터 +12 m/s (151 km/h) |
| 가속 | 13 m/s², 최고속에 가까울수록 감소 (0→100 km/h 약 3초, 계산값) |
| 브레이크 | 28 m/s², 떼면 자동 가속 재개 |
| 조향 | 2.0 rad/s × 속도 계수, 고속에서 최대 30% 감쇠 |
| 드리프트 | DRIFT를 누른 채 조향 0.3 이상, 속도 12 m/s 이상, 지면 접촉. 그립 9 → 2.6, 회전 ×1.2 |
| 드리프트 보상 | 충전 0.45 이상 → 미니부스트 0.55초, 0.9 이상 → 1.1초 |
| 부스터 게이지 | 드리프트 중 초당 0.32 × 조향 계수로 충전, 가득 차면 BOOST로 2.2초 |
| 벽 충돌 | 정면 각도에 비례해 최대 45% 감속, 벽면 방향으로 꺾음, 진동 25~90ms |
| 카트 충돌 | 최대 18% 감속 + 밀어내기, 진동 20~60ms |
| 아이템 피격 | 스핀 1~1.2초, 속도 ×0.3, 이후 1.5초 무적 |
| 진동 | 전역 쿨다운 300ms, 강도 0.15 미만 무시, 진폭 = 강도 × 사용자 강도 |
| 경기 | 기본 3랩, 2~8명, 체크포인트 8개, 첫 완주 후 15초 안에 들어오지 못하면 DNF |
| 동률 | 완주 이벤트가 처리된 순서(물리 프레임 순서)로 순위를 정합니다 |
| 복구 | 맵 아래로 6m 이상 추락하거나, 주행 중 3초 이상 1.5 m/s 미만이면 마지막 안전 지점으로 복귀 |
| 역주행 | 트랙 반대 방향으로 1초 이상 주행하면 경고 |

## 기울기 조향
- `roll = atan2(g[axis], sqrt(g.other² + g.z²))`: 화면을 뒤로 젖힌 각도와 상관없이 좌우 회전만 측정합니다.
- 기본값: 감도 1.0(0.5~2.0), 데드존 3°, 최대각 28°, 스무딩 0.08초, 축 x
- Godot는 모바일에서 화면 방향에 맞춰 센서 축을 돌려준다고 가정했습니다. 실기기 검증이 필요하며, 기기마다 다르면 "센서 축"과 "좌우 반전" 설정으로 맞춥니다.

## 아이템 (오프라인 아이템전)
| 아이템 | 효과 | 앞순위 가중치 → 뒷순위 가중치 |
|---|---|---|
| MISSILE | 바로 앞 순위 카트를 트랙을 따라 추적, 맞으면 스핀 | 1 → 4 |
| SHIELD | 6초 동안 피격 1회 방어 | 3 → 2 |
| TURBO | 1.6초 동안 +14 m/s | 2 → 4 |
| PETAL TRAP | 뒤에 설치(0.6초 후 활성), 밟으면 스핀 | 4 → 1 |
상자는 3초 후 다시 생기고, 아이템 사용 쿨다운은 1초입니다.
