# OPEN ISSUES / 다음 우선순위

## P0 (출시 차단)
1. **실기기 검증**: Android 기기에서 기울기 축·부호, 진동, FPS, Safe Area, 백그라운드 복귀를 확인해야 합니다. iOS는 Mac에서 Xcode 서명과 실행이 필요합니다.
2. **서버 권한 레이스**: 현재 LAN 모드는 클라이언트가 보고한 위치를 그대로 씁니다. 헤드리스 Godot 전용 서버가 입력을 받아 시뮬레이션하고 클라이언트가 예측·재조정하는 구조로 바꿔야 합니다.
3. **인터넷 대전**: 초대 코드 → 게임 서버 주소 매칭, UDP 게임 서버 호스팅(VM 등, **비용 승인 필요**)
4. **Firebase 실제 연결**: 프로젝트 생성, 규칙·Functions 배포(Blaze 플랜 필요), 에뮬레이터 규칙 테스트, App Check
