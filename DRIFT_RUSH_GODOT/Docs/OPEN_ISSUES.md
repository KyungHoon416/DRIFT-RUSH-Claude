# OPEN ISSUES / 다음 우선순위

## P0 (출시 차단)
1. **실기기 검증**: Android 기기에서 기울기 축·부호, 진동, FPS, Safe Area, 백그라운드 복귀를 확인해야 합니다. iOS는 Mac에서 Xcode 서명과 실행이 필요합니다.
2. **완전 서버 권한 물리**: 전용 서버와 서버 측 위치 검증(순간이동·트랙 이탈 거부, 위치 보정)까지는 구현했습니다. 남은 일은 서버가 입력을 받아 직접 시뮬레이션하고 클라이언트가 예측·재조정하는 구조입니다.
3. **인터넷 대전 배포**: 전용 서버 바이너리는 동작합니다. 남은 일은 UDP를 연 VM 호스팅(**비용 승인 필요**)과, 초대 코드 → 서버 주소 매칭(Firebase `startRace`의 `GAME_SERVER_ADDR`)입니다.
4. **Firebase 실제 연결**: 프로젝트 생성, 규칙·Functions 배포(Blaze 플랜 필요), 에뮬레이터 규칙 테스트, App Check
